# TruthfulQA Dataset

- **Benchmark:** TruthfulQA (Lin et al., ACL 2022)
- **License:** Apache License 2.0
- **Format:** CSV file containing questions, Best Answer (ground truth), Best Incorrect Answer (adversarial misconception), and human annotations across 38 categories.
- **Evaluation Subset:** 100 diverse questions sampled deterministically (seed=42), producing 200 balanced QA evaluation pairs (100 True, 100 False).
